# Aşk Akvaryumu

Karı koca iki köpekbalığı, **Kaptan** ve **İnci**, için tarayıcıda çalışan bir besleme oyunu.

Açık adres: https://lees3n.github.io/kopekbaligi/

Akvaryuma dokunarak mama bırak, midye biriktir, dükkândan süs al. İkisi de tok ve mutluysa birlikte yüzer, kalpler çıkar, bazen öpüşürler. Açlık gerçek zamanda azalır; isimler ve ilerleme bu cihazda saklanır.

Saf HTML, CSS ve JavaScript (canvas). Kurulum gerekmez.
